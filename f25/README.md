# F25 白卡體檢報告預審系統（MVP）

送審前的格式自我檢查工具。全程在瀏覽器本機處理，不上傳文件。

> 本工具只做格式預審，不是 F25 正式認證。目前以「A4、單頁、彩色」為暫定基準。

## 部署到 GitHub Pages
1. 建立 repo，把 `index.html` 放在根目錄。
2. Settings → Pages → Source 選 `main` 分支、`/ (root)`。
3. 等待約 1 分鐘，開啟 `https://<帳號>.github.io/<repo>/`。

## 操作流程
1. 閱讀用途說明與隱私說明。
2. 拖曳或選擇 PDF / JPG / PNG。
3. 系統自動檢查：頁數、色彩、方向、A4 比例、解析度、清晰度、邊緣裁切、印章區域。
4. （選用）按「執行本機 OCR」自動帶入姓名、日期、院所；逐欄核對並勾選確認項目。
5. 按「產生預審結果」：通過／待確認／不符合，並列出原因。
6. 按「下載預審 PDF」，在列印視窗選「另存為 PDF」。

## 判定規則（暫定）
| 狀態 | 條件 |
|---|---|
| 不符合 | 多頁、灰階或黑白、檔案損毀、空白頁 |
| 待確認 | 橫向、比例不像 A4、解析度低、模糊、可能裁切、欄位未填或未勾選確認、簽章未確認 |
| 通過 | 所有項目皆通過 |

門檻參數集中在 `index.html` 的 `RULE` 物件，取得正式範例後調整即可。

## 隱私設計
- 文件只在記憶體中分析，不寫入 localStorage、網址或紀錄；重新整理或「清除文件」即釋放。
- 頁面設定 Content-Security-Policy，只允許連線到程式庫 CDN（PDF.js、Tesseract.js 與中文模型）。
- OCR 只下載辨識模型，文件本身不離開瀏覽器。
- 報告姓名預設遮蔽，縮圖預設不附。
